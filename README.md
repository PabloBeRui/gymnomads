# 🌍 GymNomads

![GymNomads Logo](frontend/public/images/gymnomads/logo/logo-gymnomads.png)

## 🎓 Proyecto Final DAW - Pablo Bellón Ruibal

Bienvenido a **GymNomads**, una plataforma integral diseñada para conectar a viajeros y entusiastas del fitness con gimnasios en **toda España**. Este repositorio contiene el código fuente completo del **Proyecto Final del Ciclo de Desarrollo de Aplicaciones Web (DAW)**, desarrollado por **Pablo Bellón Ruibal**.

El objetivo de la aplicación es permitir a los usuarios entrenar en diferentes ciudades españolas mediante una suscripción flexible, facilitando el acceso a múltiples instalaciones deportivas sin necesidad de matrículas individuales en cada gimnasio local.

---

## 🏗️ Arquitectura del Proyecto

El proyecto está dividido en tres componentes principales:

1.  **📂 bbdd**: Scripts SQL para la creación y poblado de la base de datos MySQL.
2.  **🚀 backend**: API RESTful construida con Node.js, Express y MySQL.
3.  **💻 frontend**: Aplicación web SPA construida con React, TypeScript y Vite.

---

Para poner en marcha el proyecto en tu entorno local, sigue estos pasos generales. **Para instrucciones detalladas, consulta el `README.md` dentro de cada carpeta.**

### 1. Base de Datos (`/bbdd`)
Configura tu servidor MySQL y ejecuta los scripts en el orden indicado para crear la estructura y los datos de prueba.

### 2. Backend (`/backend`)

Instala las dependencias, configura el archivo `.env` y arranca el cliente de desarrollo (Puerto 5173).
👉 [Ver instrucciones del Frontend](./frontend/README.md)

# 🌍 GymNomads

![GymNomads Logo](frontend/public/images/gymnomads/logo/logo-gymnomads.png)

## 🎓 DAW Final Capstone Project - Pablo Bellón Ruibal

Welcome to **GymNomads**, a comprehensive platform designed to connect travelers and fitness enthusiasts with gyms **across Spain**. This repository contains the full source code for the **Web Application Development (DAW) Final Project**, developed by **Pablo Bellón Ruibal**.

The goal of the application is to allow users to train in different Spanish cities through a flexible subscription, facilitating access to multiple sports facilities without the need for individual memberships at each local gym.

---

## 🏗️ Project Architecture

The project is divided into three main components:

1.  **📂 bbdd**: SQL scripts for creating and seeding the MySQL database.
2.  **🚀 backend**: RESTful API built with Node.js, Express, and MySQL.
3.  **💻 frontend**: SPA web application built with React, TypeScript, and Vite.

---

## 🚀 Quick Start Guide

To set up the project in your local environment, follow these general steps. **For detailed instructions, please refer to the `README.md` inside each folder.**

### 1. Database (`/bbdd`)
Configure your MySQL server and run the scripts in the indicated order to create the structure and test data.
👉 [See DB instructions](./bbdd/README.md)

### 2. Backend (`/backend`)
Install dependencies, configure the `.env` file, and start the server (Port 3000).
👉 [See Backend instructions](./backend/README.md)

### 3. Frontend (`/frontend`)
Install dependencies, configure the `.env` file, and start the development client (Port 5173).
👉 [See Frontend instructions](./frontend/README.md)
