# Manuales de Documentación de GymNomads

Esta carpeta contiene manuales detallados para los diferentes roles de usuario en la plataforma GymNomads, disponibles en varios idiomas.

## Estructura

- `docs/manual/user/`: Manuales para usuarios estándar.
- `docs/manual/manager/`: Manuales para gestores de gimnasios.
- `docs/manual/admin/`: Manuales para administradores.

Dentro de cada carpeta de rol (`user`, `manager`, `admin`), encontrarás los manuales en los siguientes idiomas y formatos PDF:

-   **Español (ES)**: `Manual de {Rol}_ES.pdf` (Ej: `Manual de Usuario_ES.pdf`)
-   **Inglés (EN)**: `{Role} Manual_EN.pdf` (Ej: `User Manual_EN.pdf`)
-   **Catalán (CAT)**: `Manual d’{rol}_CAT.pdf` (Ej: `Manual d’usuari_CAT.pdf`)
-   **Gallego (GAL)**: `Manual de {rol}_GAL.pdf` (Ej: `Manual de usuario_GAL.pdf`)
-   **Euskera (EUS)**: `{Rol}aren eskuliburua_EUS.pdf` (Ej: `Erabiltzailearen eskuliburua_EUS.pdf`)

# GymNomads Documentation Manuals

This folder contains detailed manuals for the different user roles within the GymNomads platform, available in various languages.

## Structure

- `docs/manual/user/`: Manuals for standard users.
- `docs/manual/manager/`: Manuals for gym managers.
- `docs/manual/admin/`: Manuals for administrators.

Within each role folder (`user`, `manager`, `admin`), you will find the manuals in the following languages and PDF formats:

-   **Spanish (ES)**: `Manual de {Role}_ES.pdf` (e.g., `Manual de Usuario_ES.pdf`)
-   **English (EN)**: `{Role} Manual_EN.pdf` (e.g., `User Manual_EN.pdf`)
-   **Catalan (CAT)**: `Manual d’{role}_CAT.pdf` (e.g., `Manual d’usuari_CAT.pdf`)
-   **Galician (GAL)**: `Manual de {role}_GAL.pdf` (e.g., `Manual de usuario_GAL.pdf`)
-   **Basque (EUS)**: `{Role}aren eskuliburua_EUS.pdf` (e.g., `Erabiltzailearen eskuliburua_EUS.pdf`)
